**PersonaCUABench** evaluates computer-use agents through the people they serve. It holds tasks fixed while varying user personas, letting agents interact with requests that may omit requirements, add constraints, or call for approval before consequential actions.

The benchmark distinguishes task completion from meeting a user's expressed needs, examining both agent performance and user satisfaction.
