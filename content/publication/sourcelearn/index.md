**SourceLearn** studies how LLM agents can progressively learn from a persistent authoritative source. It builds a reusable source model that represents how knowledge is structured, interpreted, and applied.

Self-directed learning revisits incompletely understood material, while task-guided learning uses downstream experience to identify gaps. Updates remain grounded in the authoritative source.
